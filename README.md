# SafeSpot（工程名 SafeEYE）

> **基于「找不同 / 找隐患」的交互式安全合规应知应会平台**  
> 本地优先 · 真实现场图 · 法规绑定 · 考核计分 · 学情分析

数据全部落在本机 **SQLite + 本地图片**，适合厂区/内网离线部署，默认**不上传云端**。

---

## 1. 快速开始

### 1.1 环境要求

- Node.js 18+（推荐 20+；Node 26 需 `better-sqlite3` 能正常编译/预编译）
- macOS / Linux / Windows

### 1.2 安装与启动

```bash
# 在项目根目录
npm run install:all    # 安装 root + server + client
npm run dev            # 同时启动后端 :3000 与前端 :5173
```

浏览器打开：**http://localhost:5173**

| 入口 | 地址 | 说明 |
|------|------|------|
| 学员端 | http://localhost:5173/#/play | 默认入口：选卷、考试、龙虎榜 |
| 管理端 | http://localhost:5173/#/admin | 需管理口令 |

### 1.3 默认账号与口令

| 用途 | 账号 / 口令 | 说明 |
|------|-------------|------|
| 管理端入口 | 口令 **`safeeye`** | 可用环境变量 `ADMIN_PIN` 修改 |
| 学员登录（可选） | **`admin` / `admin123`** | 人员组织中创建的账号；也可访客手填姓名开考 |

### 1.4 分终端启动（可选）

```bash
# 终端 1 — 后端
cd server && npm install && npm start    # http://localhost:3000

# 终端 2 — 前端
cd client && npm install && npm run dev  # http://localhost:5173
```

### 1.5 健康检查

```bash
curl http://localhost:3000/api/health
```

端口占用时：

```bash
PORT=3010 npm run server --prefix server
```

## 2. 推荐使用流程（端到端）

```text
① 管理端登录
    → 人员组织：建部门 / 建学员账号
    → 知识与风险：维护场景·大类·细则（可先用预置 5 大场景）
    → 图库标注：上传现场图 → 框选隐患 → 绑定条款 → 保存
    → 组卷中心：勾选已标注图 → 设总分/计分规则/限时 → 发布
② 学员端
    →（可选）学员登录 或 手填姓名
    → 选正式考核 / 练习 → 选卷 → 找隐患 → 交卷
③ 管理端
    → 成绩报表：流水与导出 CSV
    → 学情分析：按试卷 / 部门（含子部门）切片分析
```

**注意：** 组卷中心只显示**已保存标注**的图片。上传后必须在「图库标注」中框选并点 **保存标注**。

## 3. 学员端使用说明

入口：`#/play`

### 3.1 学员登录（可选）

- 顶栏 **「学员登录」**：使用「人员组织」中创建的用户名/密码。  
- 登录后身份自动带入开考信息，成绩绑定 `user_id`，龙虎榜按账号去重更准。  
- 也可不登录，以**访客**手填姓名开考。

### 3.2 开考三步

1. **模式 + 试卷**  
   - **正式考核**：进正式榜与学情分析（默认 `mode=exam`）  
   - **练习模式**：可更多提示，成绩记为练习，**默认不进正式龙虎榜**  
2. **身份登记**  
   - 姓名必填；可从名册选择；部门/工号可选  
3. **规则确认**  
   - 题量、总分、计分规则、容错次数、限时（若有）→ 开始

### 3.3 答题规则

| 规则 | 说明 |
|------|------|
| 命中 | 点击落在标注矩形/椭圆内得分（圆按椭圆方程判定） |
| 误点 | 空白处点击计无效点击；单题默认容错 **3** 次后揭晓 |
| 计分 | 按试卷「权重倒挤」或「均分」；满分不超过卷面总分 |
| 限时 | 组卷时若设置整卷秒数，到时强制揭晓 |
| 结果 | 得分、等第（优/良/中/差）、**PRI 识别熟练度**、错题/遗漏条款 |

### 3.4 龙虎榜

- 右侧 **排行榜**：同人同卷取最高分（默认）  
- **全部交卷**：原始多次记录  
- 正式榜默认只看考核成绩，不含练习

## 4. 管理端使用说明

入口：`#/admin`，口令默认 **`safeeye`**

| 菜单 | 功能 |
|------|------|
| **图库标注** | 多图上传、框选圆/方、绑定知识、检索、保存/删除案例 |
| **组卷中心** | 勾选已标注图、总分/加权或均分/限时、草稿或发布、卷集管理 |
| **知识与风险** | 场景→大类→细则 CRUD；5×5 风险字典（L×C 权重） |
| **人员组织** | 多级部门、用户增删改启停、分级部门选择 |
| **成绩报表** | 成绩流水筛选、CSV 导出、知识薄弱侧栏（仅遗漏） |
| **学情分析** | 试卷/部门树过滤、KPI、图表、L1/L2/L3、PRI、结论 |
| **数据巡检** | 表数据透视、历史 JSON 清理 |

### 4.1 图库标注要点

- 支持 **多选上传**；中文文件名自动修复乱码，界面显示可读名。  
- 绘制：矩形 / 圆形；`Shift`/`Ctrl` 可约束等比。  
- 标注后须选场景→大类→细则，再保存。  
- 未保存切换图片会提示；关闭页有脏数据保护。

### 4.2 组卷要点

- 仅「已标注」案例可组卷。  
- 可设：卷名、说明、**卷面总分**、**赋分规则**（权重/均分）、**整卷限时（秒，0=不限）**。  
- **草稿**仅管理端可见；**发布**后学员端可选。  
- **删除试卷不删除历史成绩**（`records` 保留，`exam_name` 快照仍可查）。

### 4.3 人员组织

- 部门支持多级（父子树）；新建/编辑时上级部门为分级列表。  
- 人员：创建登录账号、编辑资料、禁用/启用。  
- 演示账号：`admin` / `admin123`（请在生产环境修改）。

### 4.4 学情分析（重点）

左侧筛选：

1. **试卷列表**（可空=全部）  
2. **部门列表（层级）**（可空=全部）  
3. **包含下级部门**（默认勾选）  
4. 点 **「开始分析」**

| 切片 | 含义 |
|------|------|
| 仅试卷 | 该卷全体考生学情 |
| 仅部门 | 该部门（可含子孙）跨卷学情 |
| 试卷+部门 | 交叉切片 |
| 全空 | 全库正式考核 |

指标说明（简要）：

- **知识薄弱**：只统计「遗漏 unfound」，**不含**空白处误点（避免 `unknown`）  
- **PRI 识别熟练度**：综合找全率、容错浪费、速度、无效点击率  
- **结论**：规则引擎生成可执行建议  

算法详述见：

- [`docs/ANALYTICS_ALGORITHM_MODEL.md`](./docs/ANALYTICS_ALGORITHM_MODEL.md)  
- [`docs/LEARNING_ANALYTICS_DESIGN.md`](./docs/LEARNING_ANALYTICS_DESIGN.md)

### 4.5 成绩报表

- 按试卷/模式/部门/姓名筛选  
- 导出 **CSV**（Excel 可直接打开）  
- 含已删除试卷的历史成绩（标记「卷已删」）

## 5. 案例图素材包（可选导入）

目录：`server/data/assets/case-bank-generated/`

- 按知识库 5 大场景生成的写实巡检案例图（一图多隐患）  
- **未自动入库**，请自行上传并标注

3. 组卷发布

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| 组卷中心无案例 | 先在图库标注并**保存**；仅已标注图可组卷 |
| 中文文件名乱码 | 已修复 UTF-8 解码；请**重启后端**后重新上传 |
| 成绩 200 分等异常 | 已修复双计分；历史脏分可重新考试覆盖认知 |
| 删卷后成绩还在吗 | **会保留**；学情/报表仍可按 exam_id 查 |
| 薄弱点出现 unknown | 新版本仅统计遗漏；误点进 PRI，不进知识薄弱 |
| better-sqlite3 编译失败 | 在 `server` 下重装/重建原生模块；注意 Node 版本匹配 |
| 3000 端口占用 | `PORT=3010` 启动后端，或释放端口 |
