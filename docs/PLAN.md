### 0.1 已锁定决策

| ID | 决策 | 理由 |
|----|------|------|
| D-01 | **只做 Web**，不做安装包 / Electron / Tauri | 用户明确；厂区用浏览器即可 |
| D-02 | 生产形态 = **一个 Node 进程**同时提供静态页 + `/api` + 图片 | 实施只需记一个端口 |
| D-03 | 默认监听 **`127.0.0.1`**；内网开放须设 `HOST=0.0.0.0` | 避免误把管理 API 暴露到网卡 |
| D-04 | 管理端与学员端 **同一站点、不同路由**；权限在服务端按会话与角色判定 | 取消「PIN 只挡 UI」 |
| D-05 | 角色：`admin` 全权限 · `trainer` 内容与报表 · `trainee` 仅考试 | 人员表已有 `role`，必须真正生效 |
| D-06 | 正式考核 **服务端回放计分**；浏览器分数只作即时反馈 | 否则成绩不能作数 |
| D-07 | 开考后正式卷 **不下发热区坐标**；练习模式可下发解析 | 降低对照答案点击 |
| D-08 | 访客可考，但 **不能自带 `userId`**；正式工号必须登录 | 堵住名册冒充 |
| D-09 | 删卷 **保留** `records` | 培训台账 |
| D-10 | 试卷主键改为 **稳定 ID**，卷名为字段；禁止 `INSERT OR REPLACE` 按名覆盖 | 可编辑、可重名策略另行校验 |
| D-11 | 默认演示口令仅开发环境可用；生产启动若仍是 `safeeye` / `admin123` 则 **拒绝或强制修改** | 现行默认值写在文档里，不能上内网 |
| D-12 | 学情默认只统计 `mode=exam` | 练习不进正式结论 |
| D-13 | 仓库不跟踪 `node_modules`、WAL 附属文件；运行库可跟踪种子或首次生成 | 现行 git 已误跟踪约千个文件 |
| D-14 | 测试与 CI 进 W1，不做「有空再补」 | 计分是核心不变量 |
| D-15 | 合格证用 **浏览器下载 PDF / 打印页**，不依赖桌面壳 | 与 D-01 一致 |

历史决策沿用：PIN 可作 **首次引导**，正式鉴权改为会话（见 W1-A）。

## 3. W1 — 诚实 Web 底座（优先最高）

> 目标：浏览器里用的成绩可信，服务可单端口交给非开发者启动。  
> 建议工期：1–2 周。

### 3.1 W1-A 会话与权限

| ID | 任务 | 要点 | 状态 |
|----|------|------|------|
| W1-A01 | 登录发会话 | `POST /api/auth/login` 写 **httpOnly** 会话（随机 ID 存内存或 `sessions` 表）；废除请求体里的身份冒充 | ✅ |
| W1-A02 | 管理入口改为账号 | `#/admin` 使用 `admin`/`trainer` 登录，不再把 PIN 当唯一闸；开发环境可保留 PIN 引导一次后必须建会话 | ✅ |
| W1-A03 | 路由中间件 | 写操作与 `/api/admin/*`、`/api/org` 写接口必须带有效会话；`trainer` 不可改角色为 admin、不可清理库 | ✅ |
| W1-A04 | 前端统一 API | `client/src/lib/api.js`：`credentials: 'include'`，统一错误与 toast | ✅ |
| W1-A05 | 默认口令策略 | `NODE_ENV=production` 时拒绝默认 PIN/默认密码启动，或强制首次修改 | ✅ |
| W1-A06 | 名册与用户列表 | 仅登录管理角色可读；学员端不得拉取全员名册来「选择他人」 | ✅ |

### 3.2 W1-B 权威计分与考试会话

| ID | 任务 | 要点 | 状态 |

| W1-B02 | 服务端判定 | 点击只传相对坐标；服务端用标注 hit-test 返回 hit/miss；正式卷响应不含未命中热区列表 | ✅ |
| W1-B03 | 交卷重算 | `POST /api/exam-sessions/:id/submit`：按卷面快照与命中点算分；忽略客户端 `score` | ✅ |
| W1-B04 | 限时收卷 | 服务端用开始时间 + `timeLimitSec`；超时拒绝继续点击并允许提交 | ✅ |
| W1-B05 | 练习 vs 考核 | `mode` 以开考会话为准，客户端不能把练习改成 exam | ✅ |
| W1-B06 | 计分模块上收 | `hitTest` / `buildPointScoreMap` 服务端一份为准；前端可保留镜像仅作练习反馈 | ✅ |
