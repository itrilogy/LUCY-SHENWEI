# SafeSpot 产品说明

| 项 | 值 |
|----|----|
| 产品名 | SafeSpot |
| 工程名 | SafeEYE |
| 形态 | **Web 应用**（浏览器 + 本机/内网 Node 服务） |
| 版本基线 | V1.4（工程发行号 1.4.0-web）；软著材料见 `docs/软著/` |
| 日期 | 2026-08-13 |

---

## 1. 一句话

用现场照片做「找隐患」考核：安环员标注并组卷，员工在浏览器里点击作答，成绩与学情留在本厂服务器。

## 2. 为什么是 Web，不是安装包

| 选项 | 结论 |
|------|------|
| 每人装一个桌面客户端 | **不做。** 厂区终端型号杂、升级难、IT 不愿批白名单。 |
| 每人浏览器打开同一地址 | **采用。** 一台培训机或内网服务器起服务，Chrome / Edge 即可考。 |
| 纯公有云 SaaS | **不做默认形态。** 现场图与成绩默认不出厂。可在自有内网用同一套 Web。 |

Web 在这里的含义：

- 用户界面是网页，不是原生窗体。
- 部署是「一台机器跑 Node，多人用浏览器访问」。
- 可以是讲师笔记本上的 `localhost`，也可以是机房一台内网主机。

## 3. 用户与场景

| 角色 | 谁 | 在浏览器里做什么 |
|------|----|------------------|
| 系统管理员 | 安环 / 信息员 | 部门与账号、备份、口令策略 |
| 培训师 | 安环专员 | 上传现场图、标注、组卷、看报表与学情 |
| 学员 | 一线员工 | 打开考核大厅、作答、看自己的结果与榜单 |
| 访客 | 临时工 / 演示 | 手填姓名开考；**成绩不绑定正式工号** |

主路径：

```text
建部门与学员 → 维护知识树 → 上传现场图并标注
    → 组卷发布 → 员工用浏览器开考 → 报表 / 学情 / 导出
```

## 4. 产品原则

1. **Local-First**：主库 `server/data/safeeye.db`，图片 `server/data/assets/raw/`。默认无外网依赖。
2. **浏览器即客户端**：不发安装包；升级只更新服务器上的 Web 与 API。
3. **成绩必须可对账**：正式考核的分数由服务端根据点击与卷面快照计算，不以浏览器上报的数字为准。
4. **条款引用、不拷贝长文**：标注存 `clause_id`；知识库改条文后展示自动更新。历史卷面权重在发布时快照。
5. **相对坐标**：热区一律 0~1，窗口缩放后判定仍准。
6. **删卷不删史**：试卷可下线，`records` 保留培训台账。

## 5. 范围内 / 范围外

### 做

- 单机或厂区内网 Web：标注、组卷、考试、练习、龙虎榜
- 人员组织、成绩报表、CSV、学情分析
- 单端口生产托管（同一 Node 同时提供页面和 API）
- 可选 Docker，方便机房部署（仍是 Web，不是桌面程序）
- 浏览器可下载的合格证明（PDF 或打印页）
- 平板浏览器可用的考试布局（响应式，不是独立 App）

### 明确不做

| 项 | 原因 |
|----|------|
| Electron / Tauri / NSIS 安装包 | 用户已定为 Web |
| 公有云账号体系、手机验证码 | 默认不出厂；身份用本库账号 |
| 多租户 SaaS | 一厂一部署 |
| SCORM / 对接外部 LMS | 本期不排期 |
| 摄像头监考、锁屏防切屏 | Web 无法可靠做到；靠服务端判分降低作弊收益 |
| 题目类型扩展到选择题/填空 | 护城河是视觉找隐患 |
| 标注自动 AI（默认） | 可后置为可选插件，不进主计划 |

## 6. 成功标准

一套内网 Web 部署，安环员不写代码也能：

1. 发布试卷并通知员工打开链接考试  
2. 导出本月成绩 CSV  
3. 回答「这张卷谁没考、谁没过、哪类隐患最容易漏」  
4. 备份两个目录即可换机器恢复  

在达成第 2、3 条之前，成绩只宜作培训过程数据，不宜作合规考核唯一依据。
