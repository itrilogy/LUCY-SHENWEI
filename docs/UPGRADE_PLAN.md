## 0. 升级总目标

将 SafeEYE 从「功能闭环完整的本地工程 MVP」升级为：

> **可交付的本地优先 EHS 视觉培训应用**：  
> 管理端可生产题库，学员端可独立考核，成绩可对账导出，部署可一键启动，数据仍保持本地不出厂。

### 0.1 不变的设计约束（改造红线）

| 约束 ID | 红线 | 验收问法 |
|--------|------|----------|
| C-01 | **Local-First**：核心数据在 `server/data/safeeye.db` + `assets/raw` | 断网能否完整跑通「标注→组卷→考试→成绩」？ |
| C-02 | **零外部 DB 进程**：仅 `better-sqlite3` | 是否引入了需单独安装的 MySQL/Postgres 等？ |
| C-03 | **相对坐标**：标注/点击一律 0~1 ratio | 改变窗口尺寸后 Hit-Test 是否仍准确？ |
| C-04 | **知识引用**：标注只存 `clause_id`，不拷贝长文 | 改知识库条文后，旧标注展示是否自动更新？ |
| C-05 | **便携迁移**：拷贝工程/`data` 目录可迁移 | 换机器后库与图片是否仍关联正确？ |
