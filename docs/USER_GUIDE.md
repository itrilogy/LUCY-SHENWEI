# SafeSpot 使用手册

与根目录 [README.md](../README.md) 分工：README 讲是什么和怎么启动；本文讲 **在浏览器里怎么操作**。  
产品是 **Web 应用**。开发时页面在 `:5173`，接口在 `:3000`；生产将变为 **一个端口**，见 [DEPLOY.md](./DEPLOY.md)。

软著登记用的《用户操作手册》见 [软著/04_用户操作手册.md](./软著/04_用户操作手册.md)；产品说明、功能说明见 [软著/](./软著/00_文档索引.md)。

## 一、打开系统

### 开发

```bash
npm run install:all
npm run dev
```

- 学员：http://127.0.0.1:5173/#/play  
- 管理：http://127.0.0.1:5173/#/admin  

生产只开一个端口：`npm start` 后访问 http://127.0.0.1:3000

### 开发凭据

| 角色 | 凭据 |
|------|------|
| 管理端 | 账号 `admin` / `admin123`（培训师角色也可进） |
| 开发口令 | 可选，默认 `safeeye` |
| 学员登录演示 | 同上 `admin` / `admin123` |

现场部署请立刻改掉上述默认值。`NODE_ENV=production` 时若仍是默认口令/密码将拒绝启动。

## 二、管理端

地址：`#/admin` → 使用管理员或培训师账号登录。

### 2.1 人员组织

1. 打开 **人员组织**。  
2. **部门**：名称 + 上级（分级缩进）→ 添加；有子部门时不能直接删。  
3. **人员**：姓名、登录名、初始密码、工号、部门、角色。  
4. 列表可改资料、重置密码（留空不改密）、启用/停用。  
5. 学员用该账号在考核大厅登录。  
6. 批量导入：人员列表旁「导入 CSV」，表头可用 `real_name,username,password,employee_no,department,role`（Excel 另存为 CSV UTF-8）。部门不存在时会自动创建。

`admin` 可管理全部；`trainer` 可维护题库与报表，但不能创建管理员或清理数据库。学员账号无法调用管理接口。

### 2.2 知识与风险

三级结构：

- L1 业务场景（如建设施工）  
- L2 问题大类（如高处坠落）  
- L3 考核细则（描述 + 法规条文）  

风险字典：可能性 × 后果 → 标注时的权重参考。  
系统预置 5 个场景、约 32 条细则，可直接用来标。

### 2.3 图库标注

1. 打开 **图库标注**，可多选上传图片（中文文件名会纠乱码）。  
2. 选矩形或圆形，拖拽框选隐患；`Shift` / `Ctrl` 锁定等比。  
3. 弹出层必须选 场景 → 大类 → 细则。  
4. 可拖动、缩放已有框。  
5. 点 **保存标注**。未保存的图不能组卷。  
6. 搜索框支持多词 AND（如 `消防 通道`）。  

未保存切换图片或关页会提示。  

可选素材：`server/data/assets/case-bank-generated/`，对照其中 `MANIFEST.json` 绑定条款。

### 2.4 组卷中心

1. 左侧只勾选 **已标注** 图。  
2. 填写卷名、说明。  
3. 卷面总分、赋分（权重 / 均分）、整卷限时秒数（0 = 不限）。  
4. **保存草稿** 或 **发布试卷**。  
5. 右侧：发布/取消发布、进入试考、删除。  

删除试卷 **不会删除历史成绩**。报表和学情仍可按该卷查询（标记「卷已删」）。

考卷集里点铅笔可回载到组卷区编辑；可用 ↑↓ 调整题序。新卷使用稳定 ID，改名不会冲掉旧卷。发布时会冻结该卷隐患权重。右侧日历可把试卷布置给部门并设截止日期。

### 2.5 成绩报表

- 筛选：试卷、模式（考核/练习/全部）、部门、姓名  
- 流水含用时、是否删卷  
- **导出 CSV** 可用 Excel 打开  
- 侧栏薄弱点 **只统计遗漏**，不含空白误点  

### 2.6 学情分析

1. 选试卷、部门（可空），默认包含下级部门。  
2. 点 **开始分析**。  
3. 页签：总览结论、图表、知识 L1/2/3、组织对比、识别熟练度。  

| 选择 | 含义 |
|------|------|
| 全空 | 全库正式考核 |
| 仅试卷 | 该卷全体 |
| 仅部门 | 该部门（可含子孙）跨卷 |
| 都选 | 交叉切片 |

指标说明：[ANALYTICS.md](./ANALYTICS.md)。左侧可选近 7/30/90 天。成绩报表在选定试卷后显示未考/未过并可导出。

### 2.7 数据巡检

查看表数据样例；可清理历史 JSON 碎片。  
「清理重复图与失效学情」会删掉：已有标注副本的未标注重复图，以及试卷已不存在的遗留成绩和无主学情。生产环境应仅管理员使用。

## 三、学员端

地址：`#/play`

### 3.1 登录与访客

- **学员登录**：顶栏 → 人员组织中的账号。  
- **访客**：不登录，开考时填姓名。  
- 登录后身份会带入开考页。  

访客只能手填自己的姓名，不能点选他人账号。登录后成绩绑定会话里的 `user_id`。

### 3.2 考试步骤

1. 选 **正式考核** 或 **练习**。  
2. 选已发布试卷。  
3. 确认身份。  
4. 看题量、总分、规则、容错、限时 → 开始。  
5. 在图上点可疑位置：绿=命中，红=误点。  
6. 找全、容错用尽或到时后可看解析，再下一题或交卷。  
7. 结果页：分数、等第、PRI、遗漏条款。  

宽屏右侧是龙虎榜。平板点右下角奖杯打开榜单；考试中点「条款 / 下一题」打开解析抽屉。  
培训机可开 `#/play?kiosk=1` 隐藏管理入口。合格学员可在结果页「打印合格证」（浏览器打印为 PDF）。

限时到点后服务端拒绝继续点击，并自动交卷。

### 3.3 正式 vs 练习

| | 正式考核 | 练习 |
|--|----------|------|
| 默认上正式榜 | 是 | 否 |
| 默认进学情 | 是 | 否 |
| 提示 | 偏考核 | 更利于学习 |

## 四、计分与等第

- **权重倒挤**：按隐患权重占总额的比例分配卷面分，最后一点补差。  
- **均分**：总分均分到每个隐患。  
- **等第**（得分率）：≥90 优 · ≥75 良 · ≥60 中 · 否则差。  
- **PRI**：0–100 的识别熟练度，误点多会降低。  

分数由服务端按开考时的卷面快照计算，浏览器提交的数字无效。

## 六、故障速查

| 问题 | 处理 |
|------|------|
| 页面无样式或接口失败 | 开发时确认后端已起；看 `/api/health` |
| 组卷无图 | 是否点了「保存标注」 |
| 上传中文名乱码 | 重启后端再传 |
| 管理端进不去 | 口令是否为当前 `ADMIN_PIN` |
| 学员登录失败 | 账号是否启用、密码是否对 |
| 学情是空的 | 要有正式考核交卷；练习默认不进主统计 |
| 删卷后成绩 | 正常保留 |
