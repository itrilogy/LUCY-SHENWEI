# SafeSpot 详细使用手册

> 与根目录 [README.md](../README.md) 互补：README 偏总览与启动；本文偏**操作步骤**。  
> 版本对应：学情分析 v1.3+ · 人员组织 · 中文上传修复

## 一、安装启动

### 1. 一键方式（推荐）

```bash
cd SafeEYE          # 或你的工程目录
npm run install:all
npm run dev
```

- 前端：http://localhost:5173  
- 后端：http://localhost:3000  

### 2. 默认凭据

| 角色 | 凭据 |
|------|------|
| 进入管理端 | 口令 `safeeye`（`ADMIN_PIN` 可改） |
| 学员登录演示 | 用户 `admin` / 密码 `admin123` |

## 二、管理端操作

地址：`http://localhost:5173/#/admin` → 输入管理口令。

### 2.1 人员组织

**目标：** 建好部门树和可登录学员。

1. 打开 **人员组织**。  
2. **部门**  
   - 输入名称 → 选择上级（分级缩进）→ 添加  
   - 悬停部门 → 铅笔编辑 / 垃圾桶删除  
   - 删除前需先处理子部门  
3. **人员**  
   - 底部表单：姓名、登录用户名、初始密码、工号、**分级部门**、角色  
   - 列表「编辑」可改资料、重置密码（留空不改密）、启停状态  
4. 学员之后可用该账号在学员端登录。

### 2.2 知识与风险

**目标：** 维护可绑定的隐患字典。

1. 打开 **知识与风险**。  
2. 三级结构：  
   - L1 **业务场景**（如建设施工现场）  
   - L2 **问题大类**（如高处坠落隐患）  
   - L3 **考核细则**（具体违章描述 + 法规条文）  
3. 风险字典：可能性 × 后果 → 动态权重（标注分值参考）。  
4. 系统预置 5 大场景约 32 条细则，可直接用于标注。

### 2.3 图库标注

**目标：** 把现场图变成可考题。

1. 打开 **图库标注**。  
2. **上传**  
   - 支持多选图片  
   - 中文文件名会自动纠正乱码，列表显示可读名  
3. **标注**  
   - 选矩形/圆形工具，拖拽框选隐患  
   - `Shift`/`Ctrl`：等比绘制  
   - 弹出框：场景 → 大类 → 细则（勿跳过）  
   - 可拖动/缩放已有框  
4. 点 **保存标注**（未保存不能用于组卷）。  
5. 可用搜索框多关键词 AND 检索（如：`消防 通道`）。

**可选素材包：**  
`server/data/assets/case-bank-generated/`  
见其中 `README.md` 与 `MANIFEST.json`，上传后按条款 ID 框选绑定。

### 2.4 组卷中心

**目标：** 发布学员可见试卷。

1. 左侧勾选**已标注**案例（无标注时会出现引导提示）。  
2. 填写卷名、说明。  
3. 设置：  
   - 卷面总分（如 100）  
   - 赋分：比例（按隐患权重）/ 均分  
   - 整卷限时秒数（0 = 不限）  
4. **保存草稿** 或 **发布试卷**。  
5. 右侧卷集：发布/取消发布、进入试考、删除。  

**删除试卷：** 只删卷和题目关联，**历史成绩仍保留**，可在报表/学情中查看（标记卷已删）。

### 2.5 成绩报表

1. 筛选：试卷、模式（考核/练习/全部）、部门、姓名。  
2. 查看流水：时间、分数、用时、是否卷已删。  
3. **导出 CSV** 用 Excel 打开。  
4. 右侧「知识薄弱」仅统计**遗漏**，不含误点。

### 2.6 学情分析

1. 左侧选择：  
   - **试卷**（可空）  
   - **部门**（层级列表，可空）  
   - **包含下级部门**（默认勾选）  
2. 点 **开始分析**（改筛选后需再点一次）。  
3. 查看 Tab：  
   - **总览结论**：KPI + 规则结论 + 薄弱 Top  
   - **图表看板**：PRI 分布、得分率分桶、L1/L3、子部门 PRI  
   - **知识 L1/2/3**：遗漏率、掌握度、严重度  
   - **组织对比**：部门/人员/下级拆解  
   - **识别熟练度**：PRI 刻度、高误点场次  

**四种切片：**

| 选择 | 模式 |
|------|------|
| 都不选 | 全库 |
| 只选试卷 | 试卷分析 |
| 只选部门 | 部门分析（可含子孙） |
| 都选 | 试卷 × 部门 |

算法说明：`docs/ANALYTICS_ALGORITHM_MODEL.md`。

### 2.7 数据巡检

- 查看各表样例数据（含 `attempt_stats`、`knowledge_error_facts`）。  
- 可清理历史 JSON 碎片（谨慎使用）。

## 三、学员端操作

地址：`http://localhost:5173/#/play`

### 3.1 登录与访客

- **学员登录**：顶栏按钮 → 输入人员组织中的账号。  
- **访客**：不登录，开考时手填姓名即可。  
- 登录后可「退出登录」。

### 3.2 考试流程

1. 选择 **正式考核** 或 **练习模式**。  
2. 选择已发布试卷，查看说明与题量/总分/限时。  
3. 身份：登录自动填充，或名册选择，或手填。  
4. 确认规则后开考。  
5. 在图上点击可疑位置：  
   - 绿：命中并计分  
   - 红闪：误点，消耗容错  
6. 全部找到或容错用尽/超时 → 可看解析 → 下一题或交卷。  
7. 结果页：分数、等第、PRI、无效点击、遗漏条款；可再考或回大厅。  
8. 右侧龙虎榜：排行榜 / 全部交卷 切换。

### 3.3 正式 vs 练习

| | 正式考核 | 练习 |
|--|----------|------|
| 默认上正式榜 | 是 | 否 |
| 学情分析默认统计 | 是 | 否（报表可选看） |
| 隐患总数显示 | 偏考核隐藏策略 | 更利于学习 |

## 四、计分与等第（摘要）

- **权重倒挤**：各隐患 `scoreWeight` 占总权重比例 × 卷面总分，末项补差使总和精确等于总分。  
- **均分**：总分均分到每个隐患点。  
- **服务端钳制**：入库分数不超过卷面总分。  
- **等第**（相对卷面总分百分比）：≥90 优 · ≥75 良 · ≥60 中 · 否则差。  
- **PRI**：识别熟练度 0–100，误点多则降低（详见算法文档）。

## 五、数据备份与迁移

整包拷贝即可迁移（Local-First）：

```text
server/data/safeeye.db
server/data/assets/raw/
```

建议定期备份 `safeeye.db` 与 `raw` 目录。

## 六、故障排查速查

| 问题 | 处理 |
|------|------|
| 页面无样式/接口失败 | 确认后端 3000 已启动；看 `/api/health` |
| 组卷无图 | 标注后是否点了「保存标注」 |
| 上传中文名乱码 | 重启后端后再传；已修 multer UTF-8 |
| 管理端进不去 | 口令是否为 `safeeye` 或你的 `ADMIN_PIN` |
| 学员登录失败 | 用户是否 active；密码是否正确 |
| 学情无数据 | 是否有**正式考核**交卷；练习默认不进学情主统计 |
| 删卷后成绩 | 正常保留；报表里可筛该 exam_id |
