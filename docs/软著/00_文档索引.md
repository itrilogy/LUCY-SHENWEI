## 3. 推荐提交组合（软著惯例）

1. **申请表**（版权中心在线填报，字段见 `01`）  
2. **鉴别材料一**：源代码前连续 30 页 + 后连续 30 页（见 `06`）  
3. **鉴别材料二**：文档任选其一为主、其余作补充：  
   - `04_用户操作手册.md`（推荐主件）  
   - 或 `03_功能说明书.md` / `02_产品说明书.md`  
4. **权利归属证明**（由权利人出具；要点见 `08`）
