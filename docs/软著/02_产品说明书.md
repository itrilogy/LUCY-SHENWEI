## 2. 产品概述

### 2.1 一句话

用现场照片做「找隐患」考核：培训人员在浏览器中标注并组卷，学员点击作答，成绩与学情留在本厂服务器。

### 2.2 要解决的问题

传统安全应知应会培训多为试卷或课件，难以把「现场会不会看」练成可记录、可对账的能力。本软件把考核做成视觉找茬：隐患画在真实场景图上，学员在图上指出位置，系统判定命中、计分并汇总薄弱点。

### 2.3 产品形态

本软件是 **Web 应用**，不是桌面安装包，也不是独立移动 App。

| 项 | 说明 |
|:---|:---|
| 用户界面 | 浏览器网页（Chrome / Edge） |
| 服务 | 一台机器运行 Node.js 进程 |
| 开发 | 页面 `:5173`，接口 `:3000` |
| 生产 | **同一端口**同时提供页面、API 与图片（默认 `:3000`） |
| 访问 | 讲师笔记本 `localhost`，或机房内网主机 |
| 数据 | 部署机 SQLite + 本地图片目录，默认不上公有云 |

培训机可使用 `#/play?kiosk=1` 隐藏管理入口。窄屏（平板）与宽屏共用同一套页面，通过响应式布局适配，**没有单独的 mobile 站点**。

## 3. 用户与场景

| 角色 | 典型使用者 | 在浏览器中的工作 |
|:---|:---|:---|
| 系统管理员 `admin` | 安环 / 信息员 | 部门与账号、备份、口令、审计、数据巡检 |
| 培训师 `trainer` | 安环专员 | 上传现场图、标注、组卷、报表与学情 |
| 学员 `trainee` | 一线员工 | 考核大厅作答、查看本人结果与榜单 |
| 访客 | 临时工 / 演示 | 手填姓名开考；成绩不绑定正式工号 |

主路径：

```text
建部门与学员 → 维护知识树 → 上传现场图并标注
    → 组卷发布 → 员工用浏览器开考 → 报表 / 学情 / 导出
```

## 4. 产品原则

1. **本地优先**：主库 `server/data/safeeye.db`，图片 `server/data/assets/raw/`。默认无外网依赖。  
2. **浏览器即客户端**：升级只更新服务器上的页面与接口。  
3. **成绩可对账**：正式考核分数由服务端根据点击坐标与卷面快照计算。  
4. **条款引用**：标注保存 `clause_id`；知识库改条文后展示跟随更新；发布时冻结权重快照。  
5. **相对坐标**：热区使用 0～1 比例，窗口缩放后判定仍准。  
6. **删卷留史**：试卷可下线，历史 `records` 作为培训台账保留。  

---

## 5. 主要能力（产品层）

1. 多级部门与账号；人员 CSV 导入；角色分权。  
2. 三级知识树（场景 / 大类 / 细则）与 5×5 风险字典。  
3. 现场图上传、矩形/椭圆标注、绑定细则、保存后组卷。  
4. 草稿 / 发布、赋分规则、整卷限时、部门布置与截止日期。  
5. 正式考核与练习；访客与登录学员分流。  
6. 点击命中判定、容错、限时自动交卷、解析与合格证打印。  
7. 成绩流水、CSV、未考/未过名单。  
8. 学情切片与识别熟练度 PRI。  
9. 操作审计、数据巡检、重复图与失效学情清理。  
10. 备份恢复、题包导入导出、可选 Docker 部署。

## 6. 范围外（本期不做）

| 项 | 说明 |
|:---|:---|
| Electron / Tauri / 安装包 | 已定为 Web |

| 默认可选 AI 自动标注 | 可后置，不进本版主功能 |

## 7. 运行与数据边界

- 生产默认监听 `127.0.0.1`；内网开放须显式设置 `HOST=0.0.0.0`。  
- `NODE_ENV=production` 时若仍使用默认管理口令或默认管理员密码，进程拒绝启动。  
- 合格证由浏览器打印为 PDF 或纸质页，仅证明本系统内一次考核结果，**不构成法定安全资质**。  

---

## 8. 成功标准（产品验收）

一套内网 Web 部署后，培训人员不写代码即可：

1. 发布试卷并让员工用链接考试；  
2. 导出成绩 CSV；  
3. 回答「谁没考、谁没过、哪类隐患最容易漏」；  
4. 备份数据库与图片目录后换机恢复。
