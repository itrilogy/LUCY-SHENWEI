## 1. 引言

### 1.1 编写目的

说明本软件的总体结构、功能模块、关键算法与主要接口，供软件著作权登记鉴别及维护使用。

### 1.2 术语

| 术语 | 说明 |
|:---|:---|
| 热区 | 图上隐患区域，矩形或椭圆，坐标为相对比例 0～1 |
| 条款 | 知识树 L3 细则，标注通过 `clause_id` 引用 |
| 卷面快照 | 发布/开考时写入 `exam_items.item_meta` 的隐患集合与权重 |
| 正式考核 / 练习 | `mode=exam` 进正式榜与学情；`mode=practice` 默认不进 |
| PRI | Perception Readiness Index，识别熟练度 0～100 |
| kiosk | `#/play?kiosk=1`，隐藏管理入口的培训机模式 |

### 1.3 运行环境

| 层级 | 要求 |
|:---|:---|
| 客户端 | Chrome / Edge 近两个大版本 |
| 服务端 | Node.js 20 LTS；Express 5；better-sqlite3 |
| 存储 | SQLite 单文件 + 本地图片目录 |
| 生产 | 单进程同时托管静态页、`/api`、`/assets` |

## 2. 总体结构

```text
厂区浏览器
  #/play 学员     #/admin 管理
           │ HTTP
           ▼
┌─────────────────────────────┐
│  Node.js · Express          │
│  会话 / 考试引擎 / 计分     │
│  生产：托管 client/dist     │
└─────────────┬───────────────┘
              │
     ┌────────┴────────┐
     ▼                 ▼
 safeeye.db      assets/raw/
```

前端：React 19 + Vite + Tailwind，Hash 路由。  
后端：`server/src/app.js` 聚合 HTTP；领域逻辑拆在 `examEngine`、`scoring`、`hitTest`、`analytics`、`session`、`auth`、`backup` 等模块。

## 3. 功能模块

### 3.1 身份认证与会话

- 入口：`server/src/auth.js`、`session.js`；前端 `lib/userAuth.js`、`lib/adminAuth.js`  
- 账号密码经 scrypt 校验；登录写入 `auth_sessions`，浏览器持有 **httpOnly** 会话。  
- 角色：`admin` 全权限；`trainer` 内容与报表；`trainee` 仅考试。  
- 开发可用 `ADMIN_PIN` 引导；生产禁止默认口令。  
- 访客可考，但不能自带他人 `userId`。

### 3.2 人员与组织

- 组件：`PersonnelManager.jsx`；导入：`personnelImport.js`  
- 多级部门（有子部门不可直接删除）。  
- 人员：姓名、登录名、密码、工号、部门、角色、启停、重置密码。  
- CSV 导入，表头兼容 `real_name,username,password,employee_no,department,role`；部门不存在则创建。

### 3.3 知识树与风险字典

- 组件：`KnowledgeManager.jsx`；表：`knowledge_scenes` / `_categories` / `_items`、`risk_dictionary`  
- L1 业务场景 → L2 问题大类 → L3 考核细则（描述 + 法规摘要）。  
- 风险：可能性 × 后果，供标注权重参考。  
- 预置约 5 个场景、30 余条细则。失败提示在页内展示，不使用系统 `alert`。

### 3.4 现场图标注

- 组件：`AnnotationEngine.jsx`；上传：multer  
- 多图上传，中文文件名纠码。  
- 矩形 / 椭圆拖拽；`Shift`/`Ctrl` 锁定等比；框可再拖动缩放。  
- 每框必须绑定 L1→L2→L3。坐标存 0～1。  
- **保存标注** 后才进入组卷可选列表。  
- 卫生：按文件名 stem 识别同图重复上传。

### 3.5 组卷与发布

- 组件：`TestAssembler.jsx`、`ExamManager.jsx`  
- 仅已标注图可入卷；稳定试卷 ID，卷名为字段。  
- 设置：卷面总分、权重倒挤 / 均分、整卷限时秒数（0=不限）。  
- 草稿或发布；发布时把隐患权重写入 `item_meta` 快照。  
- 可布置部门、截止日期、必考/选考。  
- 删卷保留 `records`。

### 3.6 考试编排与交互判题

- 大厅 / 结果 / 画布：`ExamLobby.jsx`、`ExamResult.jsx`、`InteractionJudge.jsx`  
- 步骤：选模式 → 选已发布卷 → 确认身份 → 看规则 → 开考。  
- `POST /api/exam-sessions` 开考；点击只传相对坐标。  
- 正式卷揭晓前 **不下发热区坐标**；练习可下发解析。  
- 单题默认容错 3 次；限时到点服务端拒绝继续点并自动交卷。  
- 宽屏右侧龙虎榜；窄屏抽屉。`kiosk=1` 隐藏管理入口。

### 3.7 命中判定与计分

- `hitTest.js`：点是否落入矩形或椭圆（相对坐标）。  
- `scoring.js`：权重倒挤（按隐患权重占总额比例分配，尾差补齐）或均分；等第 ≥90 优 / ≥75 良 / ≥60 中 / 否则差。  
- `examEngine.js`：维护开考状态、命中集合、`session_log`，交卷按快照计分，**忽略客户端上报的 score**。

### 3.8 成绩报表与导出

- 组件：`ReportsDashboard.jsx`  
- 筛选：试卷、模式、部门、姓名。  
- 流水含用时、是否已删卷。  
- CSV 导出。侧栏薄弱点 **只统计遗漏（unfound）**。  
- 选定试卷后可看未考 / 未过名单。

### 3.9 学情分析

- 后端：`analytics.js`；前端：`AnalyticsDashboard.jsx`  
- 切片：试卷、部门（默认含下级）、近 7/30/90 天；默认 `mode=exam`。  
- 交卷后物化 `attempt_stats`、`knowledge_error_facts`，与成绩同事务。  
- 双轨：`hit` 进掌握度与 PRI；`miss`（空白误点）只进 PRI；`unfound` 进知识薄弱与 PRI。  
- PRI：

```text
PRI = 100 × (0.40 M_hit + 0.25 (1−W) + 0.15 η' + 0.20 (1−R_miss))
```

`M_hit` 找全率，`W` 容错浪费，`η'` 命中速度归一，`R_miss` 无效点击占比。  
知识掌握度：节点贝叶斯平滑 `(H+1)/(E+2)`。

### 3.10 数据巡检与卫生

- 组件：`DBInspector.jsx`；逻辑：`cleanup.js`  
- 表样例预览；清理历史 JSON 碎片。  
- 删除：已有标注副本的未标注重复图；试卷已不存在的遗留成绩与无主学情。

### 3.11 操作审计

- `audit.js`、`AuditDashboard.jsx`  
- 记录管理端关键写操作（登录、组卷、删卷、导入、卫生清理等），供事后对账。

### 3.12 备份、题包与托管

- `backup.js` / `backup-cli.js`：`npm run backup` / `restore`，打包数据库与图片。  
- `bankPack.js`：题包导入导出（zip，内存接收）。  
- `start-prod.js`：构建后单端口托管 `client/dist`。  
- 可选 Docker Compose。  

### 3.13 品牌与声明

- 产品 SVG 徽标 `safespot.svg`；实验室主标官方 `LUXI LAB.svg` 同步件。  
- 点击顶栏打开应用声明（产品/数据/成绩/使用约定 + 出品双标）。

## 5. 主要接口（摘要）

| 类别 | 示例 |
|:---|:---|
| 健康 | `GET /api/health` |
| 登录 | `POST /api/auth/login` · `GET /api/auth/me` · `POST /api/auth/logout` |
| 考试 | `POST /api/exam-sessions` · 点击坐标 · 交卷 |
| 管理 | `/api/admin/*`（标注、试卷、人员、报表、学情、审计、卫生、备份） |
| 静态 | 生产托管 `client/dist`；图片 `/assets/raw/*` |

管理接口默认要求培训师或管理员会话；已发布卷列表、开考、龙虎榜对学员开放。

---

## 6. 安全设计要点

1. 成绩服务端回放，客户端分数不入库。  
2. 正式卷开考前不返回热区。  
3. 身份取自会话，禁止访客绑定他人工号。  
4. 生产拒绝默认口令；默认绑定本机回环地址。  
5. 审计记录关键写操作。
