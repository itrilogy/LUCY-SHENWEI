## 1. 系统简介

SafeSpot 是在浏览器中使用的安全生产培训软件。培训人员把现场照片上的隐患框出来并出卷，员工在图上点击作答。成绩保存在本单位服务器，默认不上传公有云。

打开方式：在已启动服务的机器上，用 Chrome 或 Edge 访问系统地址（开发环境一般为 `http://127.0.0.1:5173`，生产环境一般为 `http://服务器:3000`）。

| 入口 | 地址后缀 | 说明 |
|:---|:---|:---|
| 学员考核大厅 | `#/play` | 选卷、考试、龙虎榜 |
| 管理端 | `#/admin` | 标注、组卷、人员、报表 |
| 培训机 | `#/play?kiosk=1` | 隐藏「管理端」按钮 |

本软件 **没有独立的手机 App 或 /m 站点**。手机和平板打开的是同一套页面。

## 2. 登录

### 2.1 管理端

1. 打开 `#/admin`。  
2. 输入管理员或培训师的账号、密码。  
3. 开发环境可改用开发口令（默认仅开发可用）。  

角色权限：管理员可管理全部；培训师可维护题库与报表，不能创建管理员或做库级清理；学员账号不能调用管理接口。

### 2.2 学员

1. 打开 `#/play`，点顶栏「学员登录」。  
2. 使用「人员组织」中创建的账号。  
3. 也可不登录，在开考身份步骤手填姓名（访客）。访客不能点选他人账号。  

现场部署必须修改出厂默认账号密码。

### 2.3 应用声明

点击左上角 SafeSpot 标志，可查看产品声明、数据边界、成绩责任与出品单位。

## 3. 管理端操作

### 3.1 人员组织

1. 进入「人员组织」。  
2. 添加部门：填写名称，可选上级部门。有下级部门时不能直接删除。  
3. 添加人员：姓名、登录名、初始密码、工号、部门、角色。  
4. 可修改资料、重置密码（留空表示不改）、启用或停用。  
5. 批量导入：选择 CSV（UTF-8）。推荐表头：`real_name,username,password,employee_no,department,role`。部门不存在时自动创建。  

### 3.2 知识与风险

维护三级结构：

- 第一级：业务场景（如建设施工）  
- 第二级：问题大类（如高处坠落）  
- 第三级：考核细则（文字描述 + 法规摘要）  

风险字典为「可能性 × 后果」对照表，供标注时参考权重。系统预置若干场景与细则，可直接用于标注。

### 3.3 图库标注

1. 进入「图库标注」，选择一张或多张现场照片上传。  
2. 选择矩形或圆形工具，在图上拖出隐患范围。按住 Shift 或 Ctrl 可锁定比例。  
3. 在弹出层选择场景 → 大类 → 细则。  
4. 可再拖动或缩放已有框。  
5. 点击 **保存标注**。未保存的图片不能组卷。  
6. 搜索框支持多个词同时匹配（例如「消防 通道」）。  

切换图片或关闭页面前若有未保存修改，系统会提示。

### 3.4 组卷中心

1. 在左侧勾选 **已经保存标注** 的图片。  
2. 填写试卷名称、说明。  
3. 设置卷面总分、赋分方式（按隐患权重 或 平均分配）、整卷限时秒数（填 0 表示不限时）。  
4. 保存草稿，或直接发布。  
5. 在右侧可将试卷发布/取消发布、试考、删除；可用上下箭头调整题目顺序。  
6. 可用日历把试卷布置给指定部门，并设置截止日期与是否必考。  

删除试卷 **不会删除** 已经产生的成绩记录。改试卷名称不会覆盖历史卷。

### 3.5 成绩报表

- 可按试卷、模式（正式考核 / 练习 / 全部）、部门、姓名筛选。  
- 流水中含用时，以及该卷是否已被删除。  
- 「导出 CSV」可用电子表格软件打开。  
- 侧栏「薄弱点」只统计交卷时仍未找到的隐患，不含点在空白处的误点。  

### 3.6 学情分析

1. 选择试卷、部门（可空）。默认包含该部门的下级。  
2. 点击「开始分析」。  
3. 查看总览结论、图表、知识层级、组织对比、识别熟练度。  

| 选择 | 含义 |
|:---|:---|
| 都不选 | 全部正式考核 |
| 只选试卷 | 该卷全体考生 |
| 只选部门 | 该部门跨卷情况 |
| 都选 | 交叉查看 |

正式考核默认进入学情；练习默认不进入主结论。

### 3.7 数据巡检与审计

- 数据巡检：查看各表样例；可清理重复未标注图、已删试卷留下的成绩与学情。生产环境建议仅管理员操作。  
- 操作审计：查看管理端关键操作记录。

## 4. 学员端操作

### 4.1 考试步骤

1. 选择 **正式考核** 或 **练习**。  
2. 选择已发布的试卷。  
3. 确认身份（已登录则带入；否则手填姓名）。  
4. 阅读题量、总分、容错次数、限时等规则后开始。  
5. 在图片上点击认为存在隐患的位置：绿色表示点中，红色表示点空。  
6. 找全、容错用尽或到达限时后，可查看解析，再进入下一题或交卷。  
7. 结果页显示分数、等第、识别熟练度与遗漏条款。合格者可打印合格证（由浏览器打印或另存 PDF）。  

宽屏时右侧为龙虎榜。平板可点右下角奖杯打开榜单；考试中可打开条款抽屉。限时结束后不能继续点击，系统自动交卷。

### 4.2 正式考核与练习的区别

| 项目 | 正式考核 | 练习 |
|:---|:---|:---|
| 默认进入正式榜 | 是 | 否 |
| 默认进入学情 | 是 | 否 |
| 用途 | 考核与台账 | 学习与熟悉操作 |

## 5. 计分规则（使用侧）

- **按权重**：按各隐患权重占全部权重的比例分配该卷分数，余数补在最后一项。  
- **平均分**：把总分平均分到每个隐患。  
- **等第**：得分率 ≥90 为优，≥75 为良，≥60 为中，否则为差。  
- **识别熟练度（PRI）**：0 至 100 的综合指标，误点多会降低。  

屏幕上即时显示的分数仅供作答过程参考。**最终成绩以服务器计算结果为准。**

## 6. 备份（管理员）

在服务器目录执行：

```text
npm run backup
```

或复制以下两项后即可换机恢复：数据库文件 `server/data/safeeye.db`，图片目录 `server/data/assets/raw/`。恢复使用 `npm run restore`。详细步骤见发行指南。

## 7. 常见问题

| 现象 | 处理 |
|:---|:---|
| 页面打不开或接口失败 | 确认服务已启动；访问健康检查地址 |
| 组卷列表没有图 | 是否已在图库点击「保存标注」 |
| 上传后中文文件名乱码 | 重启服务后再传 |
| 管理端进不去 | 账号、密码或开发口令是否正确；是否已被停用 |
| 学情是空的 | 需要有正式考核的交卷记录 |
| 删卷后成绩还在 | 正常现象，台账保留 |
| 手机打不开单独 App | 本软件是网页，用手机浏览器打开同一地址即可 |

## 8. 注意事项

1. 本系统用于本组织内训、演练与演示。  
2. 知识库中的法规文字为引用摘要，以现行法规和本单位制度为准。  
3. 合格证只证明在本系统完成一次考核，不是行政机关颁发的资质证书。  
4. 现场图片与成绩属于本单位培训资料，请按本单位保密要求保管备份介质。
