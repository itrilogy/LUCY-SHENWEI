## 1. 环境要求

| 项 | 要求 |
|:---|:---|
| 操作系统 | Windows 10+ / macOS 12+ / Linux |
| 运行时 | Node.js 20 LTS（推荐）。更高主版本可能导致 `better-sqlite3` 原生模块编译失败 |
| 浏览器 | Chrome 或 Edge 近两个大版本 |
| 磁盘 | 视现场图片数量；另预留备份空间 |
| 网络 | 默认可本机使用；内网多人访问时开放端口并绑定 `0.0.0.0` |

本软件 **无安装包、无桌面托盘、无独立移动安装程序**。

---

## 2. 获取与安装

```text
# 1. 取得源码目录 SafeEYE
# 2. 安装依赖
npm run install:all

# 3. 复制环境变量模板并修改
cp .env.example .env
```

必须修改：

- `SESSION_SECRET`（随机长串）  
- 管理员密码（库内默认 `admin` / `admin123` 仅开发）  
- 如使用开发口令，生产禁止保持 `ADMIN_PIN=safeeye`

---

## 3. 启动

### 3.1 开发（两个端口）

```text
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。接口在 `http://127.0.0.1:3000`。

### 3.2 生产（一个端口）

```text
NODE_ENV=production npm start
```

浏览器打开 `http://127.0.0.1:3000`。内网：

```text
HOST=0.0.0.0 NODE_ENV=production npm start
```

健康检查：`GET /api/health`。

生产环境若仍为默认口令或默认管理员密码，进程将拒绝启动。

### 3.3 Docker

```text
docker compose up -d --build
```

仍为 Web 服务，不是桌面容器应用。

## 4. 数据位置

| 内容 | 路径 |
|:---|:---|
| 主库 | `server/data/safeeye.db` |
| 现场图 | `server/data/assets/raw/` |
| 备份输出 | `server/data/backups/`（运行时生成，不入库） |

备份：`npm run backup`。恢复：`npm run restore`。

---

## 6. 卸载

停止 Node 进程或 Docker 容器，删除安装目录。若需销毁培训数据，同时删除 `server/data/`。
