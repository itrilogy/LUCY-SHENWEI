# 源代码鉴别材料说明

> 依据计算机软件著作权登记对「源程序鉴别材料」的常见要求整理。  
> 页数、行数以中国版权保护中心当期《登记指南》为准。

---

## 1. 一般要求（惯例）

| 项 | 常见要求 |
|:---|:---|
| 页数 | 前连续 **30 页** + 后连续 **30 页**；不足 60 页则提交全部 |
| 每页行数 | 不少于 **50 行**（末页除外） |
| 内容 | 源程序正文；连续、无双栏；可含少量注释 |
| 页眉 | 软件全称、版本号 |
| 页脚 | 页码 |

---

## 2. 建议选取范围

本软件主体约 **11,400 行** JavaScript / JSX（`client/src` + `server/src` + `server/test`，2026-08-13 统计，不含 `node_modules`）。应提交连续源程序，避免只摘「精华」导致不连续。

### 2.1 前 30 页（入口与核心引擎）

推荐按以下顺序拼接后从头连续取足 30 页：

1. `server/src/app.js`  
2. `server/src/db.js`  
3. `server/src/auth.js`  
4. `server/src/session.js`  
5. `server/src/examEngine.js`  
6. `server/src/hitTest.js`  
7. `server/src/scoring.js`  

### 2.2 后 30 页（分析、前端编排与画布）

推荐包含目录后部连续文件，例如：

1. `server/src/analytics.js`  
2. `server/src/audit.js`  
3. `server/src/backup.js`  
4. `client/src/App.jsx`（后部）  
5. `client/src/components/User/InteractionJudge.jsx`  
6. `client/src/components/Admin/AnnotationEngine.jsx`（后部）  

### 2.3 不作为源程序主件

- `node_modules/`  
- `docs/`、`*.md`  
- 图片、SQLite 数据库文件  
- 构建产物 `client/dist/`
